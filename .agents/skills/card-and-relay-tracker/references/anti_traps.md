# 7 维发卡网与 API 中转站机读判定门禁 (Gate Check Matrix)

本项目用于对第三方发卡店铺与 API 中转站进行自动化风险拦截。在输出推荐前必须严格通过以下 7 项硬性门禁，无歧义执行。

---

## 一、发卡网 4 大拦截门禁

| 门禁 ID | 门禁名称 | 拦截级别 | 触发特征 / 关键词 | 机器处置动作 |
| :--- | :--- | :---: | :--- | :--- |
| **GATE-01** | **规格纯度门禁**<br>(防自备代充混淆) | **FAIL (一票否决)** | 命中了“代认证、单认证、自备、代充、包过、需自备、提供账号、扫码登录、只包认证、不含订阅”等服务类词汇，且用户要求为成品。 | **立即剔除该条目**。严禁作为“成品号”输出给用户。 |
| **GATE-02** | **价格真实门禁**<br>(防起步价与缓存刺客) | **FAIL (一票否决)** | 聚合站标价与落地页目标规格实选单价不一致，或落地页默认展示为“引流起步价（如已售罄的体验码）”。 | 废弃聚合站标价，**强制以落地页实测结算价为准**；无法测得实价时剔除或标记 `[待人工核验]`。 |
| **GATE-03** | **现货库存门禁**<br>(防幽灵秒发套路) | **FAIL (一票否决)** | 页面显示库存为 0，或标注“补货中、预售、拍下24小时内人工发货、排队中”。 | **立即剔除**。推荐列表中只保留 `in_stock == true` 且实时库存 > 0 的店铺。 |
| **GATE-04** | **邮箱与质保门禁**<br>(防跑路与死号) | **WARN (警示降权)** | ① 交付仅提供 Session/Cookie 无邮箱；<br>② 使用自建域名企业邮（`@xxx-mail.com`）；<br>③ 质保不足“首登质保”或苛求指定海外住宅 IP。 | ① 缺失邮箱直接剔除；<br>② 企业邮标记 `[高危自建邮]`；<br>③ 质保条款如实提取并在卡片中加粗展示。 |

---

## 二、API 中转站 3 大阻断门禁

| 门禁 ID | 门禁名称 | 拦截级别 | 触发特征 / 判据 | 机器处置动作 |
| :--- | :--- | :---: | :--- | :--- |
| **GATE-05** | **模型掺水纯度门禁** | **FAIL (一票否决)** | MODELOC / Veridrop 纯度检测得分 < 80 分，或存在将高价模型（Claude 3.7 / GPT-4o）降级转发廉价模型行为。 | **禁止推荐该中转站**。 |
| **GATE-06** | **倍率膨胀换算门禁** | **REQUIRED (强制折算)** | 宣传充值赠送（如充100送200），但设置隐蔽分组倍率与模型倍率。 | 严禁采信宣传倍率，**强制换算为每百万 Token 最终实付人民币价格**：`折算单价 = 官方牌价 × 分组倍率 × 模型倍率`。 |
| **GATE-07** | **上下文截断与逆向门禁** | **WARN (警示标记)** | 长文本输入超过 8K/16K 时静默截断无报错，或采用 Web 逆向伪装 API（缺失 Tool Use）。 | 标注实际可用上下文上限，排查逆向特征，低稳定性站点作降级处理。 |

---

## 三、输出纪律
1. **零说教原则**：严禁在回复中输出长篇大论的“购买须知”、“免责防骗指南”；
2. **高信号交付**：仅在推荐卡片中以标签形式如实呈现质保与规格（如 `[首登质保] [含一手Outlook]`）。
