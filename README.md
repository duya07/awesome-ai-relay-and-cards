## 评分体系摘要

```
综合得分 = 中立风控分 (35%) + 数据功能分 (35%) + 体验直连分 (30%)
```

- **中立与风控 (35%)**：审计开源透明度、真伪测试机制，排除隐藏推广返利外链与广告买榜。
- **数据与功能 (35%)**：自动化探针监测、现货库存实时同步、全模型覆盖与实时倍率折算。
- **体验与直连 (30%)**：国内网络免代理直连时延、现代化响应式排版、即时模糊搜索效率。
