## 🔬 三、多智能体打分体系与权重公开

```
综合得分 = 中立风控分 (35%) + 数据功能分 (35%) + 体验直连分 (30%)
```

### 1. 智能体 A：中立与风控审计 (权重 35%)
- **核心职能**：审查商业化偏见、排查暗藏邀请码、鉴别真伪测试机制。
- **加分项**：开源托管于 GitHub (+15~20分)；具备模型假充真/逆向检测证据链 (+15~20分)；公开自费测试且无抽成 (+10分)。
- **扣分/拉黑**：隐蔽推广返利链接 (-15~25分)；商业赞助未明确标明 (-5~10分)；纯单站跳转引流直接剔除（不予收录）。

### 2. 智能体 B：数据与功能评估 (权重 35%)
- **核心职能**：评估数据深度、自动化探针能力、功能全面性。
- **加分项**：7×24 真实调用探针与实时延迟刷新 (+15分)；现货库存与店铺状态同步 (+10分)；价格走势曲线与倍率换算器 (+10分)；主流模型全覆盖 (+10分)。
- **扣分项**：静态死榜单、无实时数据、长期未更新 (-15~30分)。

### 3. 智能体 C：体验与直连评估 (权重 30%)
- **核心职能**：评估国内网络友好度、页面 UI 现代化与交互清爽度。
- **加分项**：大陆免代理直连秒开 (< 0.8s) (+15分)；现代响应式 UI 排版规整 (+10分)；即时模糊搜索与多维筛选 (+10分)。
- **扣分项**：国内直连阻断需代理 (-20~35分)；弹窗骚扰与广告牛皮癣 (-10~20分)。
