## 三、打分规则与免责声明

### 1. 评分权重
```
综合得分 = 中立风控分 (35%) + 数据功能分 (35%) + 体验直连分 (30%)
```
- **中立风控 (35%)**：开源透明度、真伪测试机制、排除隐藏返利外链与广告买榜。
- **数据功能 (35%)**：自动化探针、现货库存同步、多模型全覆盖与倍率换算。
- **体验直连 (30%)**：国内直连时延、页面排版设计、搜索筛选效率、无弹窗骚扰。

### 2. 核心免责条款
1. **纯 AI 自动化评判**：全量评分由探针脚本与 AI 智能体交叉审计生成，无人工商业干预，零商业赞助。
2. **纯主观性与时效性**：评分仅代表特定采样节点的技术快照，不构成消费、充值或投资建议。第三方站点变更频繁，评分不作长期担保。
3. **资金与交易风险自负**：第三方发卡与中转站存在跑路与风控封号风险，务必小额按需使用，切勿大额沉淀资金。相关纠纷本项目概不负责。
