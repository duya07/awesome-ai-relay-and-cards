## 🔬 多智能体打分体系与权重公开

本次评测使用 3 个不同职能的 AI 子智能体，分别从三个不可替代的维度执行深度审计，满分 100 分，按权重加权计算总分：

```
综合得分 = 中立风控分 × 35% + 数据功能分 × 35% + 体验直连分 × 30%
```

### 1. 🛡️ 智能体 A：中立与风控审计师 (权重 35%)
- **核心职能**：审查商业化偏见、排查暗藏邀请码、鉴别真伪测试机制。
- **加分项**：
  - 项目开源 / 代码托管于 GitHub (+15~20分)
  - 具备真实的假模型/掺假/逆向充官转检测证据链（如 Veridrop、TokenScan）(+15~20分)
  - 明确标榜并落实“自费测试、无抽成、不接受付费买榜”(+10分)
- **扣分/排除项**：
  - 检测到大量隐蔽推广返利（Affiliate 链接/邀请渠道码）(-15~25分)
  - 首页包含商业赞助置顶且未明确区分自然排名 (-5~10分)
  - **不予收录**：纯单站跳转引流或无实质聚合对比内容之站点不予收录

### 2. 📈 智能体 B：数据与功能评估师 (权重 35%)
- **核心职能**：评估数据深度、自动化探针能力、功能全面性。
- **加分项**：
  - 具备 7×24 自动化真实探针监测、实时刷新可用率与时延 (+15分)
  - 发卡网现货库存实时同步、店铺状态标记 (+10分)
  - 具备历史价格走势曲线、倍率实时换算器 (+10分)
  - 主流模型（Claude 3.5 Sonnet、GPT-4o、DeepSeek、o1 等）全覆盖 (+10分)
- **扣分项**：
  - 静态死榜单、无价格数据、长期未更新 (-15~30分)

### 3. ⚡ 智能体 C：体验与直连评估师 (权重 30%)
- **核心职能**：评估国内网络友好度、页面 UI 现代化与交互清爽度。
- **加分项**：
  - 国内大陆网络免代理直连秒开（< 0.8s 响应）(+15分)
  - 现代响应式 UI（Next.js / Vue / Tailwind），卡片与表格排版规整 (+10分)
  - 支持即时模糊搜索、多属性快速筛选 (+10分)
- **扣分项**：
  - 国内直连超时阻断、必须挂代理才能打开 (-20~35分)
  - 页面充斥弹窗、诱导加群、广告牛皮癣 (-10~20分)
